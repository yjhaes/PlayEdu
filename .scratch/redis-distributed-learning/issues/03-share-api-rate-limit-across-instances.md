# 03: 让 API 请求配额跨实例共享

**What to build:** 让同一客户端 IP 的请求配额在所有 API 实例之间共享，使负载均衡不能放大可用配额，同时保持现有白名单、响应头和配置能力。

**Blocked by:** 01: 建立 Redis 运行基线

**Status:** ready-for-agent

- [ ] 建立聚焦的请求限流模块，使用 Redisson 令牌桶而非通用计数接口。
- [ ] 限流速率沿用现有外部配置，客户端 IP 在所有应用实例之间共享同一配额。
- [ ] OPTIONS 与既有白名单行为保持不变。
- [ ] 限流响应继续暴露配额、剩余额度和 HTTP 429 行为，且剩余额度不出现无意义负值。
- [ ] Redis 故障时请求限流明确失败，不切换为每节点独立配额。
- [ ] 集成测试覆盖令牌补充、合理突发、额度耗尽和恢复。
- [ ] 双客户端验证不同 IP 不共享配额。
- [ ] 双实例验证同一 IP 的总可用配额不会按实例数量翻倍。
- [ ] Maven 测试通过。
