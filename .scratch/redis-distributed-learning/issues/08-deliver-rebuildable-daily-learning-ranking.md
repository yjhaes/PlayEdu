# 08: 交付可重建的实时学习榜

**What to build:** 让管理员在 Dashboard 快速查看今天和昨天的学习时长 Top 10，并确保 Redis 投影丢失时能够从 MySQL 权威数据恢复。

**Blocked by:** 01: 建立 Redis 运行基线; 05: 原子保存权威学习数据

**Status:** ready-for-agent

- [ ] 使用按自然日分桶的 Redis ZSet 保存学习榜，成员为学员标识，分值为已确认学习时长。
- [ ] 仅在 MySQL 学习事务提交后异步增加排行榜分值。
- [ ] Redis 更新失败不回滚 MySQL，并产生结构化日志和可观测指标。
- [ ] Dashboard 从 Redis 返回今天和昨天的 Top 10，并正确装配学员展示信息。
- [ ] 产品查询范围限制为今天和昨天，排行榜 key 默认保留七天。
- [ ] 应用在投影缺失时能够从 MySQL 重建今天和昨天的榜单。
- [ ] 提供受权限保护且可重复执行的手动重建操作，不暴露通用缓存管理能力。
- [ ] 重建过程使用 MySQL 作为唯一事实来源，多次执行得到相同结果。
- [ ] 集成测试覆盖少于十人、超过十人、并列分值、跨自然日、异步失败和清空后重建。
- [ ] 管理端受影响页面构建通过，Maven 测试通过。
