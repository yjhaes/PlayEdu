# 07: 让 PC 与 H5 使用学习租约

**What to build:** 让 PC 与 H5 播放器遵循活跃学习租约协议，使用户开始、持续、暂停、结束或切换学习时都能获得一致的计时与冲突反馈。

**Blocked by:** 06: 建立活跃学习租约 API

**Status:** ready-for-agent

- [ ] PC 与 H5 在视频开始实际播放时立即发送第一次心跳，并保存服务端返回的学习会话标识。
- [ ] 播放期间按十秒周期使用同一会话标识续租，不把播放器进度当作可信学习时长提交。
- [ ] 暂停、播放结束和主动切换课时时调用停止学习操作。
- [ ] 页面关闭或跳转时使用浏览器尽力发送能力释放当前学习租约，服务端 TTL 仍作为最终兜底。
- [ ] 多课时冲突时暂停第二个视频，显示明确且一致的用户提示，不继续静默发送计时心跳。
- [ ] Redis 或心跳接口暂时不可用时不显示虚假的时长成功状态，并允许用户重试。
- [ ] 旧标签页不得使用过期会话标识停止新标签页的活跃学习课时。
- [ ] PC 与 H5 的课程播放、进度展示和视频结束行为没有无关回归。
- [ ] 两个前端的生产构建通过。
