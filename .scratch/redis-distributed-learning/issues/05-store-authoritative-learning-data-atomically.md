# 05: 原子保存权威学习数据

**What to build:** 让一次有效学习区间产生的课时进度、课程进度和每日学习时长成为一致的 MySQL 事实，并使同一学员同一天的并发增量不会丢失或生成重复统计行。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 数据迁移识别并合并同一学员、同一自然日的历史重复统计行，合并结果保留完整时长。
- [ ] 迁移完成后建立学员与自然日的唯一约束。
- [ ] 每日学习时长使用数据库原子 UPSERT 累加，不再先查询旧值后在应用内相加。
- [ ] 一次有效学习区间的课时进度、课程进度和每日学习时长在同一个事务中提交。
- [ ] 任一权威写入失败时整个事务回滚，不产生部分学习结果。
- [ ] 事务提交后形成包含学员、自然日和已确认增量的排行榜更新事件 seam。
- [ ] 排行榜事件不会在 MySQL 事务回滚时对外生效。
- [ ] MySQL 集成测试覆盖重复数据迁移、唯一约束、并发 UPSERT 和事务回滚。
- [ ] 高并发累计后的最终时长等于全部有效增量之和，且每天只有一条统计记录。
- [ ] Maven 测试通过。
