# 08: 交付学员积分中心 API

**What to build:** 提供 H5 与 PC 共用的积分摘要、流水、商品、兑换、已交付码和规则接口，并严格限制为当前登录学员的数据。

**Blocked by:** 04, 06

**Status:** ready-for-agent

- [ ] 积分摘要返回 `credit1` 当前余额。
- [ ] 积分流水分页只返回当前学员的变化值、类型、原因、时间和余额快照。
- [ ] 商品列表返回名称、价格、上下架可见性和精确可用库存；售罄商品保留并显示零库存。
- [ ] 兑换接口要求幂等键，并明确区分余额不足、库存不足、商品下架和重复请求。
- [ ] 我的兑换分页只返回当前学员记录；详情接口按需解密对应兑换码。
- [ ] 积分规则接口统一提供两端使用的永久积分、不可取消、无失效码售后和负余额说明。
- [ ] 现有前台拦截器继续以 `is_lock` 阻断锁定学员；不引入 `is_active` 新语义。
- [ ] 接口测试覆盖越权访问、锁定、分页、售罄、解密和规则内容。
