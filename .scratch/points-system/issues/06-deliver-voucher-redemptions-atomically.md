# 06: 原子完成积分兑换与自动发码

**What to build:** 在余额和库存充足时原子扣除积分、领取一枚兑换码、创建兑换记录和流水，并保证并发及重试不会重复发码。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] 兑换只允许未锁定学员和在售商品，每次只兑换一枚码。
- [ ] 兑换使用客户端幂等键或稳定请求键，重复请求返回同一结果。
- [ ] 兑换事务原子领取一枚 `AVAILABLE` 码，余额不足或无库存时不产生任何变化。
- [ ] `credit1` 扣减使用余额充足条件，人工造成的负余额不能继续兑换。
- [ ] 同事务创建价格快照兑换记录、扣分流水，并将码改为 `DELIVERED`。
- [ ] 一枚兑换码最多关联一次兑换；同一学员在库存允许时可重复兑换同一商品。
- [ ] 成功后返回可在“我的兑换”再次查看的兑换记录。
- [ ] 不实现取消、退分、补码、失效码售后或有效期判断。
- [ ] 并发测试证明余额不透支、库存不为负、一枚码不重复发放。
