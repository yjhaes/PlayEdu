# 04: 原子发放首次课程完成奖励

**What to build:** 在服务端确认课程首次完成时，与现有学习事实同事务发放 10 积分，并向前端返回本次实际奖励结果。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 调整课程完成写入接口，显式返回 `未完成 → 已完成` 的状态跃迁，而不是只暴露最终状态。
- [ ] 所有可学习课程使用统一 10 积分奖励，不增加课程级配置字段。
- [ ] 在线奖励与学习事实在同一个 MySQL/Spring 事务内提交。
- [ ] 学员与课程组成稳定唯一奖励键，同一课程终身最多奖励一次。
- [ ] 学习记录删除、重置、重学或新增课时后再次完成不扣回也不重复奖励。
- [ ] 商品售罄或下架不影响奖励发放。
- [ ] 学习心跳响应仅在本次实际发放时返回 `earned_points = 10` 或等价字段。
- [ ] 测试覆盖重复和并发完成、事务回滚、学习记录重置以及无库存奖励。
