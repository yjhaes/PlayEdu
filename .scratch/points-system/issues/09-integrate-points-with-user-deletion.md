# 09: 将积分数据接入学员物理删除

**What to build:** 重构现有学员删除为跨模块事务，删除学员全部积分与兑换关联数据，同时保留兑换码的已发放状态且不保留学员关联。

**Blocked by:** 02, 06

**Status:** ready-for-agent

- [ ] 建立跨 common、course 和 points 服务的事务删除门面，Controller 不再先删用户再依赖无事务事件补清理。
- [ ] 删除学员时物理删除其积分流水和兑换记录，并随用户行删除 `credit1`。
- [ ] 不在兑换码表保存 `user_id`；删除兑换记录后无法从兑换码反查原学员。
- [ ] 已交付兑换码继续保持 `DELIVERED`，永不回到可兑换库存。
- [ ] 待发放兑换码不受学员删除影响。
- [ ] 现有部门、学习、每日时长、登录记录清理行为保持完整并纳入同一事务。
- [ ] 锁定和部门变化不会清空或修改积分；解锁后既有数据恢复可访问。
- [ ] 测试覆盖正余额、负余额、已兑换、无兑换和删除中途失败回滚。
