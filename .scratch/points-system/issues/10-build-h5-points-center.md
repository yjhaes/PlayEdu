# 10: 构建 H5 积分中心

**What to build:** 在 H5“我的”入口提供完整积分中心、课程奖励提示、兑换确认、售罄展示和已交付码查看体验。

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] “我的”页增加积分余额和积分中心入口，余额允许显示负数。
- [ ] 积分中心包含余额、流水、兑换商品、精确库存和我的兑换。
- [ ] 商品售罄时显示“已兑完”和零库存，不隐藏商品或提供候补。
- [ ] 兑换确认框展示商品、价格、不可取消和失效码无系统内售后。
- [ ] 兑换成功后展示并可复制兑换码；关闭页面后可在“我的兑换”再次查看。
- [ ] 首次课程完成实际获得奖励时提示“获得 10 积分”并可跳转积分中心。
- [ ] 积分规则页长期展示全部已定关键条款。
- [ ] 余额不足、商品下架、库存不足和请求重试均有明确反馈。
- [ ] H5 TypeScript 严格检查和生产构建通过。
