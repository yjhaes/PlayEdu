# 07: 交付超级管理员积分运营能力

**What to build:** 为现有超级管理员提供积分调整、商品、库存、兑换和流水管理页面与后台 API，并阻止普通管理员访问。

**Blocked by:** 02, 03, 06

**Status:** ready-for-agent

- [ ] 所有积分后台入口除认证外显式校验现有 `BackendBus.isSuperAdmin()`。
- [ ] 普通管理员看不到积分菜单、路由，并在直接请求 API 时被拒绝。
- [ ] 支持按学员提交非零积分调整和必填自由文本原因，允许调整为负余额。
- [ ] 支持创建最小商品、下架、原价补货、受约束删除和查看精确库存。
- [ ] 支持兑换码逐行粘贴导入、重复跳过报告和未交付码直接删除。
- [ ] 支持按需解密查看兑换码；不新增明文查看专用审计。
- [ ] 提供可搜索、分页的积分流水、兑换记录和库存列表，不增加汇总看板或 CSV 导出。
- [ ] 商品产生已发放码后不可改价或删除，错误操作返回明确原因。
- [ ] 所有写操作和导入接入现有后台操作日志。
- [ ] 管理端生产构建和权限测试通过。
