# 03: 建立兑换商品与加密码库存

**What to build:** 支持最小兑换商品、兑换码加密存储、逐行粘贴导入、重复跳过、精确库存、补货、下架和受约束删除。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 商品只要求名称和正整数积分价格，可在售或下架。
- [ ] 兑换码使用专用外部密钥进行带认证加密，不复用 JWT 密钥。
- [ ] 为规范化兑换码计算带密钥摘要，用唯一约束阻止重复导入。
- [ ] 多行文本导入忽略空白行、规范化输入、导入新码并跳过重复码。
- [ ] 导入返回新增数、重复跳过数及对应结果，不持久化批次实体。
- [ ] 待发放码可直接物理删除，不保留撤销状态。
- [ ] 兑换码导入后不可更换商品。
- [ ] 商品支持原价补货和下架；库存按 `AVAILABLE` 精确计数。
- [ ] 一旦存在 `DELIVERED` 码，商品不可改价或物理删除；从未发码的商品删除时一并删除未交付码。
- [ ] 密文、原码和密钥不会写入日志、错误响应或导入报告。
- [ ] 测试覆盖加解密、摘要唯一性、重复导入、删除、补货和商品状态规则。
