# 11: 构建 PC 积分中心

**What to build:** 在 PC 个人菜单接入与 H5 语义一致的积分中心、课程奖励提示、兑换和已交付码体验。

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] 个人下拉菜单增加积分余额和积分中心入口，建立对应路由。
- [ ] 积分中心包含余额、流水、兑换商品、精确库存和我的兑换。
- [ ] 商品售罄时显示“已兑完”和零库存，不隐藏商品或提供候补。
- [ ] 兑换确认框展示商品、价格、不可取消和失效码无系统内售后。
- [ ] 兑换成功后展示并可复制兑换码；关闭页面后可在“我的兑换”再次查看。
- [ ] 播放页首次课程完成实际获得奖励时提示“获得 10 积分”并可跳转积分中心。
- [ ] 积分规则页与 H5 使用同一后端规则内容。
- [ ] 余额不足、商品下架、库存不足和请求重试均有明确反馈。
- [ ] PC TypeScript 严格检查和生产构建通过。
