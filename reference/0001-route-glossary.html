请求映射：四个线索

术语含义与代码线索
Controller（控制器）处理 HTTP 请求的类；本项目课程接口入口为 CourseController。
请求映射把 HTTP 请求与 Java 方法关联起来；RequestMapping 可声明公共路径。
HTTP 方法请求的一部分；GetMapping 限定 GET。仅 URL 相同不代表任何请求方法都匹配。
路径变量例如 /course/{id} 中的 id；PathVariable 绑定到方法参数。和 ?id=42 形式的查询参数不同。

本课定位法：先看类路径，再看方法路径与 HTTP 方法，最后检查参数绑定和方法体的首个调用。

路由匹配不等于权限通过或数据存在。Controller 的名称和方法名称也不自动构成请求地址。

规则来源：Spring 官方请求映射；项目事实：CourseController 源码。
