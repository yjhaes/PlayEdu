PLAYEDU / 速查 02

查询与异常

线索本课含义
Service / ServiceImpl接口声明操作，具体实现提供执行代码。
eq("id", id)查询条件：数据库 id 列等于方法参数 id。
getOne(条件)MyBatis-Plus 查询单个实体的操作。无匹配记录时为空；默认多个匹配结果会抛异常。本课按主键查询。
null没有对象引用；不等同于编号 0 或字段为空字符串。
return course正常结束方法，返回课程对象。
throws / throwthrows 声明可能抛出的异常；throw 执行抛异常动作，中断当前方法正常流程。

findOrFail：查询 → 找不到就抛异常 → 找到则返回。这个名称是项目的方法命名，不是框架自动赋予的功能。

来源：项目源码、MyBatis-Plus getOne、条件构造器。
