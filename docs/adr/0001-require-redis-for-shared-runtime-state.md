# 使用 Redis 承载跨实例运行状态

PlayEdu 将 Redis 设为强制依赖，替换现有的进程内缓存、锁和限流实现。分布式锁由 Redisson 提供，请求限流、登录失败计数和活跃学习租约分别由聚焦的模块管理；不保留内存降级，因为把锁或计数器静默退化为单进程状态会破坏多实例正确性。

## 后果

Redis 不可用时应用应启动失败；运行期间 Redis 故障时，依赖锁、限流或学习租约的同步操作应明确失败。删除通用内存工具和缓存管理接口，课程观看权限直接查询 MySQL；开发和演示环境支持外部 Redis（例如 WSL 中独立运行的 Redis）或可选的 Docker Compose 单节点 Redis，生产环境的高可用拓扑不在本次范围内。
