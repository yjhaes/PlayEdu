# 将每日学习榜建模为 Redis 查询投影

MySQL 是学习进度和每日学习时长的事实来源，Redis ZSet 只承载今天和昨天的实时学习榜。一次有效学习心跳在同一数据库事务中更新课时进度、课程进度和每日时长；事务提交后再通过异步事件更新排行榜，因此 Redis 数据可以丢失并从 MySQL 重建。

## 后果

每日时长表需要先合并重复记录，再为学员与日期增加唯一约束，并通过原子 UPSERT 累加时长。Redis 更新失败不会回滚已经提交的学习记录，排行榜允许短暂滞后，并通过启动重建、手动重建或定时校准恢复；本次不引入事务 Outbox。
